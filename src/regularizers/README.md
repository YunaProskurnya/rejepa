# Регуляризаторы

`SIGReg` и `VISReg` — независимые модули. Каждый принимает эмбеддинги независимых изображений формы `[N, D]` и возвращает скалярный регуляризационный loss. Для выхода энкодера `[B, K, D]` сначала нужно получить одно представление на изображение, например усреднить видимые токены по оси `K`.

```python
from src.regularizers import SIGReg, VISReg

regularizer = SIGReg()
loss_reg = regularizer(embeddings)
```

Loss предсказания и вес регуляризации задаются отдельно в цикле обучения.

## Формулы VISReg

В [статье VISReg, формула 6](https://arxiv.org/html/2606.02572) центр задан как квадрат L2-нормы среднего эмбеддинга: `L_center = ||mean(z, dim=0)||_2²`. На [странице авторов в псевдокоде](https://haiyuwu.github.io/visreg/) используется `.mean()`; код следует этому варианту.

При размерности `D` вариант с `.sum()` в `D` раз сильнее варианта с `.mean()` при одинаковом `center_weight`.

Для `shape_loss` код, как и псевдокод авторов, усредняет квадраты по изображениям и проекциям. Это в `N` раз меньше суммы по изображениям, усреднённой по проекциям. Определение одномерного расстояния Вассерштейна в лемме 3.2 статьи также включает деление на `N`.

Статья добавляет `eps` только в знаменатель нормализованных эмбеддингов: `centered / (std.detach() + eps)`. Псевдокод опускает `eps`. В этом проекте выбран вариант формулы статьи; `scale_loss` использует стандартное отклонение без добавки `eps`.
